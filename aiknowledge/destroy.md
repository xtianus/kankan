# Destroy (`kankan destroy`)

- Trello's `GET /1/boards/{id}/cards/closed` paged with `before=<id>` loses cards (observed 2026-11-21: three archived cards A<B<C, `limit=1` gives [C], `limit=1, before=C` gives [A], `limit=2, before=C` gives [A]). `TrelloClient.closed_cards` therefore reads once with `limit=1000`, and a full page (1000 rows) makes `destroy` refuse instead of guessing.
- `destroy` never follows symbolic links in `<gcd>/kankan`: `Ctx.open` checks the state root before `try_load` reads `config.json`; before the questions and under the lock `<gcd>/kankan`, `seats/`, `project.lock`, each seat's lock and process record and `log.jsonl` must be real directories or regular files; the project lock (`project_lock(paths, nofollow=True)`) and the audit log (`auditlog.append(follow=False)`) are opened with `config.open_nofollow`, relative to `<gcd>/kankan` opened with `O_DIRECTORY | O_NOFOLLOW`; `blocks/*/files` is listed through `O_NOFOLLOW` directory descriptors (`os.scandir(fd)`); trees are removed with unlink and rmdir only. The final state sweep still walks paths (`os.walk`, not descriptors).
- A worktree root overlapping `<gcd>/kankan` (either way, so also a root holding the repository) is refused, and so is any registered worktree inside `<gcd>/kankan` whatever the root: the state sweep would delete it as plain state.
- The `pre-push` hook is removed only when it is kankan's exact content and the repository's own (`<gcd>/hooks`, or a local `core.hooksPath` inside the repository equal to the effective value); through a global `core.hooksPath` it is `shared` and kept.
- The `origin` probe runs `git -c credential.helper= ls-remote` with askpass `/bin/false`, no terminal prompt and ssh `BatchMode=yes`: an empty `credential.helper` given with `-c` (read last) also clears URL-specific helpers.
- `destroy` command-line errors use the fixed `messages.DESTROY_USAGE` (argparse's message would echo an unquoted board name).
- The board name typed by the user is read from Trello's `name`, never from the URL (the slug of `https://trello.com/b/<shortLink>/<slug>` can be an older name); the inventory prints only `https://trello.com/b/<shortLink>`.
- The project configuration and the lock files are the last things removed or kept: locks are never deleted, and a run interrupted earlier still finds the board through `config.json`. Only the `files` ref format is supported (reftable is refused).
- Re-check boundaries: under the project lock the configuration is reloaded (`Ctx.open`) and its binding, paths, integration branch, target lists and `known_seats` must equal the inventory's (local-only runs too); the agent refs (names and OIDs) and the interrupted blocks (identity: seat, short link, snapshot path, files, link flag) must be exactly those shown, whatever was confirmed; then the gate runs again and the board is read again: a different name, registry binding or board ID, a card added or now in another of kankan's lists, a new `Resume` label or a reopened seat list stops with `needs_action`, while a card that left kankan's lists is tolerated (the deletion set shrinks). Worktree changes are also caught before the first write: a worktree added or removed, or work at risk in any worktree not in the confirmed discard set (`authorised`); edits inside a worktree confirmed for discard are discarded with it (`--force`). During the board step each card is read with `card_place` right before `DELETE` (moved out → skipped), the board is read again before the `Resume` labels (now carried outside → kept) and before the registry block (a card in a target list → stop, registry and local state kept). A worktree that turns dirty after the lock re-check is caught by destroy's own re-inspection (`_reinspect`) right before its removal or by git's final check in `git worktree remove` (no `--force` unless the user accepted discarding): the run stops with `needs_action`, the worktree and state stay, the rerun finishes. A Trello outage during the inventory changes nothing; during deletion earlier deletions stay done, no local removal happens and the rerun finishes.
