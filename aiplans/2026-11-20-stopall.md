# Stop all and start Implementation Plan

**Goal:** `kankan stop` without a seat stops every agent of the project (immediately, or after their task with `--graceful`), disables autostart, checks that everything stopped and records what it stopped; `kankan start` restores it. Both are safe to repeat.

**Spec:** [stop all functional](../aispecs/stopall_spec_functional.md) (F) and [stop all technical](../aispecs/stopall_spec_technical.md) (T).

**Status:** implemented locally.

## Tasks

1. `diag.seat_recover` takes an optional comment template (T§5); `messages.STOP_FORCED`.
2. `kankan/stopall.py`: inventory, confirmation, stop record, autostart disable, immediate stop, graceful wait loop re-asserting `stop_requested`, final check, report; `start_all` and the no-record help (T§2–5).
3. `cli`: `stop [seat] [--graceful] [--yes]`, prompt on stderr, `usage_error` without a terminal and `--yes`; `start` (T§6).
4. Tests `tests/test_stopall.py`: F§6 tests 1–8, unit-level with a fake tmux/systemctl where possible and one tmux test with real launchers.
5. Docs: user manual §4 and §10, `aiknowledge/notes.md` if something durable is learned; `AGENTS.md` feature list.
