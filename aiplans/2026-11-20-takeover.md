# Takeover cleanup Implementation Plan

**Goal:** warn before `kankan init --takeover` strands cards or integrated work, and let `kankan reconcile --fix` move stranded cards back to `Backlog`.

**Spec:** [takeover functional](../aispecs/takeover_spec_functional.md) (F) and [takeover technical](../aispecs/takeover_spec_technical.md) (T).

**Status:** implemented locally.

## Tasks

1. `diag`: `SEAT_LIST_RE`, `stranded_lists`, `stranded_cards`, report `blocked_without_ref`, `_fix_stranded` under the project lock; `messages.STRANDED_MOVED` (T§2, T§4).
2. `doctor`: the reconcile check names `kankan reconcile --fix` for stranded cards (T§4).
3. `init`: `takeover_problems` and the confirmation in `_bind_registry`; warning after an accepted takeover (T§3).
4. Tests: `tests/test_init.py` (F§4 tests 1–3), `tests/test_takeover_reconcile.py` (tests 4–5).
5. Docs: user manual "Advanced usage" section with everything about takeover; `AGENTS.md` feature list.
