# kankan seat commands Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `kankan seat start|stop|remove` act on one seat: `seat stop` replaces `kankan stop <seat>`, `seat start` starts an existing seat, `seat remove [--graceful] [--yes]` removes a seat in any state and gives its cards to the board; a new Q&A conversation with nothing new since a complete answer is not prompted.

**Architecture:** a new module `kankan/seatremove.py` holds the removal: card classification into moves, immediate removal, graceful request and wait, serialized completion, autostart/stop-record adjustment. A persisted `SeatConfig.removing` flag (`"graceful"`/`"immediate"`) is read by task choice, the Q&A claim, seat acquisition, required lists, counts, `up`, the launchers and `status`. One destination helper, `cards.implemented_destination`, replaces every lookup of the implementer's `Implemented` list.

**Tech Stack:** Python ≥ 3.10, standard library only at runtime; pytest (`setsid -w .venv/bin/python -m pytest -q -n 16 --dist worksteal` for the full suite); fixtures `kproject`, `fake_trello`, `tests/flow.py` (`implement`, `review_setup`, `agent_ctx`), `tests/helpers.py` (`hold`, `put_card_ref`, `NoTmux`), `tests/launcher_helpers.py`; the `systemctl` PATH stub and the module-local tmux fixture of `tests/test_stopall.py` (copy them, they are not shared).

**Spec:** [seat functional](../aispecs/seat_spec_functional.md) (F) and [seat technical](../aispecs/seat_spec_technical.md) (T). Read both first.

**Status:** implemented locally (rulings in the execution ledger are listed in the final report); reviewed by the internal advisor and the Codex advisor (2026-11-22), findings folded into the plan and into T; the removal journal they proposed was dropped by decision (a crash between a move and its comment loses the comment).

## Global Constraints

- 4-space indentation; standard library only in `kankan/`; all user-facing texts in `kankan/messages.py`, English.
- `removing` values exactly `"graceful"` and `"immediate"`; absent means not being removed. `remove_error` is a string or absent. Old `config.json` files without them load unchanged.
- Lock order: removal lock `seats/<seat>.remove.lock` → `up.lock` → Q&A lifecycle lock → conversation lock → project lock → seat-state lock (T§6). Never wait for a launcher while holding any of them.
- Lock files are never deleted (`seats/<seat>.lock`, `.state.lock`, `.block.lock`, `.remove.lock`).
- The configuration entry of a removed seat is deleted **last** (T§6 step 5); every step is repeatable.
- kankan never commits in a seat worktree: `git merge --abort` if needed, then `git worktree remove --force` **before any card moves** (T§4 step 6).
- Card comments of a removal: `comment_once(card_id, text, f"seat-remove-{seat}-{card_id}")` right after the move, never through `transition`'s own comment (`comment=None`).
- Autostart and stop record are adjusted when a removal is **requested**; the requesting command reports the result (T§7). A crash between a move and its comment loses that comment (accepted, T§4.1).
- `kankan stop <seat>` is rejected by argparse (mapped to `usage_error` by `cli._Parser.error`). `--attach` only with `seat start`, `--kill` only with `seat recover`, `--graceful`/`--yes` only with `seat remove`.
- No new Trello endpoint: `card`, `snapshot`, `move_card`, `comment_once`, `remove_label`, `archive_list` only (checked in Task 10).
- **One commit at the end** (global git rule), with `kankan/VERSION` 0.1.9 → 0.1.10; push after committing. Tasks end with a green test run, not a commit.

## Review Focus

1. **The last seat of a type, and the last work seat** — an `Implemented` card goes to the other type's seat, then to `Backlog` parked with cause `seat_removed`, and the next reviewer is of the eligible type. Task 1 `test_implemented_list_*`, Task 4 `test_remove_last_work_seat_parks_implemented_to_backlog`, `test_cross_type_fallback_reviewed_by_other_type`.
2. **Another process acting during the removal** (a reviewer claims a card; another seat ticks after a partial archive; `seat start` racing completion) — reclassified under the lock; no `CONFIG_ERROR`; no re-created seat. Task 2 `test_partial_archive_does_not_stop_other_seat`, `test_acquire_create_false_does_not_recreate`; Task 4 `test_card_claimed_meanwhile_is_reclassified`.
3. **A removal interrupted half-way** (failed Trello move; crash after an archive; rerun after a partial run) — the rerun in a fresh `Project` completes, no comment posted twice, entry deleted last. Task 4 `test_rerun_does_not_duplicate_comments`; Task 5 `test_failed_move_*`, `test_crash_after_archive_rerun_completes`.
4. **A dead, unavailable or stuck seat; an escalation racing the launcher's own completion** — one completion only (removal lock); survivors block before any move. Task 5 `test_concurrent_completions_one_report`; Task 6 `test_survivors_block_before_moves`.
5. **Autostart absent, already lower, or `systemctl` failing; a stop record without a unit** — counts only go down, a failure ends the public command with `needs_action` after the removal completed. Task 5 `test_autostart_*`; Task 6 `test_systemctl_failure_through_seat_remove`.
